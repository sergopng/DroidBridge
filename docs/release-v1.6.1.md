# DroidBridge 1.6.1

DroidBridge запускает отдельный сервер ADB и останавливает его при выходе. Встроенный Shell, Logcat, scrcpy и Terminal, открытый из DroidBridge, подключаются к серверу текущего сеанса. Серверы, запущенные другими программами, продолжают работать.

Требуется macOS 14.4 или новее. Сборка для Apple Silicon и Intel.
