# DroidBridge 1.6

- Внизу окна и в очереди видны полоса прогресса, процент и примерное оставшееся время текущей передачи. Оценка появляется после получения данных о скорости.
- При обычной отправке по MTP файл создаётся с исходным именем. При совпадении имён вариант «Сохранить обе версии» добавляет номер и показывает итоговое имя в очереди.
- При закрытии последнего окна или выходе через ⌘Q приложение останавливает активную передачу и закрывает запущенные им scrcpy и Logcat. Если идёт прошивка Fastboot, приложение дождётся её завершения.
- Значок Finder явно указан в пакете приложения. Чтобы DroidBridge был виден в «Программах», перетащите приложение из DMG в папку «Программы».

Требуется macOS 14.4 или новее. Сборка для Apple Silicon и Intel.
