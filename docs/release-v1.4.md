# DroidBridge 1.4

Настройки scrcpy теперь открываются с раздела «Основные». FPS, размер и битрейт видео, кодеки, режимы ввода и формат записи можно выбрать из меню. Для флагов есть переключатели. В расширенном каталоге доступны поиск, справка scrcpy, произвольные значения и диагностические команды.

Требуется macOS 14.4 или новее. Поддерживаются Apple Silicon и Intel. Сборка подписана локальной подписью ad hoc и не проходила нотарификацию Apple.
