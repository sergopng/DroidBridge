# Сборка DroidBridge

Требуются macOS, актуальные Xcode Command Line Tools, Python 3 и JDK 17. Сборка проверена на Apple Silicon. Скрипт собирает универсальное приложение для Apple Silicon и Intel.

```sh
xcode-select --install
./build.sh
```

Готовое приложение находится в `image/DroidBridge.app`. Команда `./build.sh --dmg` также создаёт образ в `build/`. Сборка использует локальную подпись ad hoc.

При первом запуске скрипт скачивает зафиксированные версии Android SDK Platform Tools (ADB и Fastboot), scrcpy, libmtp, libusb и Android Build Tools. Каждый архив проверяется по SHA-256. Загрузки кешируются в `build/downloads/`. См. [условия Android SDK](https://developer.android.com/studio/terms).

Если JDK установлен вне стандартных каталогов, укажите его через `JAVA_HOME`. Если SDK по умолчанию несовместим со SwiftUI приложения, укажите путь к установленному SDK через `DROIDBRIDGE_MACOS_SDK`. При подготовке версии 1.4 использовался SDK macOS 26.5.

## Android-помощник

Исходники находятся в `src/android/`. Локальная сборка создаёт собственный ключ в `extras/helper/key.p12`. Храните ключ локально и используйте его повторно для обновлений APK. Android принимает обновление существующего APK только с совместимой подписью.

Если у вас уже есть подписанный APK, можно передать его сборщику через `DROIDBRIDGE_HELPER_APK` с абсолютным путём. В этом случае JDK и Android Build Tools для сборки приложения не понадобятся.

## Файлы проекта

- `src/` — SwiftUI, файловые операции, USB MTP на C и код Android-помощника.
- `third-party/` — патч для macOS и инструкция к исходникам библиотек.
- `build.sh` — получение зависимостей и запуск сборки.

## Публикация

Поместите содержимое папки проекта в корень репозитория GitHub. Ключи подписи, каталоги сборки и скачанные зависимости исключены через `.gitignore`. Используйте [текст релиза](docs/release-v1.6.1.md) для записи с тегом `v1.6.1`.

Перед публичным распространением выберите лицензию собственного кода. Для публикации бинарного DMG отдельно проверьте условия распространения вложенных ADB, Fastboot и scrcpy и их зависимостей. Сведения о компонентах и исходниках находятся в [THIRD_PARTY.md](THIRD_PARTY.md).
